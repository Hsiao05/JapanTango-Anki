# 日语单词背诵网站 · 离线版

这是一个纯前端静态项目，可直接用 VS Code 打开，也可双击 `index.html` 运行。推荐用 VS Code Live Server 预览。

## 已实现

- 303 条日语词库，已写入 `js/words.js`，每个单词绑定 4 位 `[0-9A-Z]` ID。
- IndexedDB 本地持久化，离线可用。
- 新用户初始化：选择「目标完成轮次」，高级参数动态估算。
- 老用户导入：粘贴引继码恢复学习记录。
- 引继码：Base64 + 自定义字符置换 + 反转，包含背诵顺序 ID、单词 ID、学习记录、全局配置和队列。
- 自动适配新旧词库：导入时过滤已删除 ID，新增 ID 自动初始化。
- 艾宾浩斯 / 动态容量 SRS：每轮容量、新词下限、复习名额、RFI 排序、日内插排、EF 和间隔更新。
- Anki 风格卡片：正面/背面动画衔接、假名/释义切换、品词/声调/意味布局。
- 粒子交互：雪、花瓣、雾纹、金币、烟花；不会遮挡手机按钮。
- 快捷键：空格翻面，1-4 评分，0 收藏，Backspace 撤回。
- 数据页：引继码导入导出、统计、单词列表、收藏切换。

## 管理词库

打开 `js/words.js`：

- 修改单词释义/读音：不要改 `id`。
- 删除单词：把对应项 `active` 改成 `false`，并把 ID 放进 `window.RETIRED_WORD_IDS`，不要复用。
- 新增单词：浏览器控制台运行：

```js
WordAdmin.nextSequentialId()
```

复制生成的顺序 ID，追加新对象到 `window.JP_WORDS` 数组末尾。

## 部署

这是静态站点，上传整个文件夹到任意静态托管服务即可。没有后端，没有外部依赖。
